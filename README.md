# ProjMap Studio

> プロジェクションマッピングツール  
> 動画・ライブカメラ・画面共有をプロジェクタで自由な形に投影できます

---

## Windows での動作

**動作確認環境**  
Windows 11 / Electron 42 / Node.js 24

**GPU 関連のトラブルが起きた場合**

```bash
npm start -- --disable-gpu
```

**パスの扱い**  
`webUtils.getPathForFile()` を使って取得しているため、Windows の `C:\...` 形式も正しく動作します。

## インストールと起動

```bash
git clone https://github.com/kolinz/projmap-studio.git
cd projmap-studio
npm install       # 初回のみ（数分かかります）
npm start
```

**必要環境**: Node.js 24 以上 / Electron 42 以上 / WebGL 対応 GPU

## 基本的な使い方

### ステップ 1 — サーフェスを追加する

左パネルの **「+ Add Surface」** をクリックすると、画面中央にサーフェス（投影エリア）が現れます。

複数のサーフェスを重ねることができます。追加するたびに色が変わります。

---

### ステップ 2 — ソースを割り当てる

サーフェスをクリックして選択（枠が光ります）してから：

| 操作 | 方法 |
|------|------|
| 動画ファイル | 「📁 Load Video」→ MP4 / WebM ファイルを選択 |
| カメラ映像 | 「📷 Live Camera」をクリック |
| 画面共有 | 「🖥 Screen Share」→ 画面またはウィンドウを選択 |

---

### ステップ 3 — 形を合わせる

サーフェスを選択した状態でハンドルをドラッグして形を調整します。

```
  ●────◆────●   ← ● コーナー（四隅）
  │           │      ◆ エッジ中点（辺の湾曲）
 ◆           ◆
  │           │
  ●────◆────●
```

| ハンドル | 動かすと… |
|----------|-----------|
| ● コーナー | 四隅を変形 — 台形や平行四辺形にできる |
| ◆ エッジ中点 | 辺を湾曲させる — 曲面への投影に使う |
| 枠の中をドラッグ | サーフェス全体を移動 |

#### グリッドスナップ
ツールバーの **「SNAP」** をONにすると、ハンドルが 1/16 グリッド（1920×1080 で 120px 間隔）に吸着します。精密な位置合わせに使えます。

調整後は **Ctrl+Z** で元に戻せます（50ステップまで）。

---

### ステップ 4 — プレビュー（実際に投影する）

1. ツールバーの **「DISPLAY」** でプロジェクタ側のモニターを選択
2. **「▶ PREVIEW」** をクリック → プレビューウィンドウが開く
3. プレビューウィンドウをプロジェクタ画面に移動・最大化

プレビュー中もエディタ側でハンドルを動かして微調整できます。

#### 緊急時
- **「■ BLACKOUT」** → 投影を瞬時に真っ暗にする
- **B キー** でも同じ操作ができます

---

### ステップ 5 — BGM を流す

左パネル **「Audio」** セクションから音声ファイル（MP3 / WAV / OGG）を読み込めます。  
動画ソースとは独立したグローバル BGM として再生されます。

| 操作 | 内容 |
|------|------|
| ▶ / ⏸ / ⏹ | 再生・一時停止・停止 |
| Volume | 音量調整 |
| ループ再生 | ループのON/OFF |

---

### ステップ 6 — プロジェクトを保存する

ツールバー **「EXPORT」** → `projmap_project.json` として保存されます。

次回は **「IMPORT」** で読み込めば、サーフェスの位置がそのまま再現されます。  
※ 動画ファイルのパスも保存されますが、ファイルを移動した場合は再度読み込みが必要です。

---

## キーボードショートカット

| キー | 操作 |
|------|------|
| `N` | サーフェスを追加 |
| `P` | Preview / Edit 切り替え |
| `B` | Blackout オン/オフ |
| `Delete` | 選択中のサーフェスを削除 |
| `Esc` | 選択を解除 |
| `Ctrl + Z` | 元に戻す |
| `Ctrl + Shift + Z` | やり直す |

---

## 座標の数値入力

サーフェスを選択すると、左パネルに **X・Y の数値フィールド** が表示されます。  
単位はツールバーの出力解像度（デフォルト 1920×1080 px）に対応しています。

例: 出力解像度 1920×1080 の場合、画面中央は `X: 960, Y: 540`

## よくある問題

**Q. プレビューウィンドウがどこかに消えた**  
A. 「DISPLAY」セレクタで正しいモニターを選んでから「▶ PREVIEW」をクリックしてください。

**Q. カメラが認識されない**  
A. Electron がカメラ権限を要求するダイアログを表示します。「許可」を選択してください。

**Q. MKV 動画が再生されない**  
A. Chromium は MKV コンテナに非対応です。MP4 形式への変換をお試しください。

**Q. プロジェクトを読み込んだら動画が映らない**  
A. ファイルを移動した場合は「📁 Load Video」で再度読み込んでください。

**Q. Linux で投影エリアの外が黒くならない**  
A. Wayland 環境では透明ウィンドウが動作しない場合があります。X11 セッションで起動してください: `GDK_BACKEND=x11 npm start`

```
├── shared/

│   └── tessellate.js        # Coons patch（renderer 共有）
├── renderer/
│   ├── index.html           # エディタ HTML
│   ├── style.css            # スタイル
│   ├── app.js               # エディタロジック（WebGL・Undo・IPC）
│   └── undo.js              # UndoHistory クラス（最大50ステップ）
└── preview/
    ├── index.html           # プレビュー HTML
    └── app.js               # フレーム受信・表示（15行）
```

### アーキテクチャ

```
座標系: [0,1] 正規化 (ウィンドウサイズ非依存)
  └─ 頂点シェーダーでクリップ空間に変換
     gl_Position = vec4(u*2-1, -(v*2-1), 0, 1)

プレビュー出力:
  エディタ WebGL canvas
    └─ canvas.toDataURL('image/jpeg') → IPC → preview <img>

  エディタが描画した内容をそのままプレビューに転送するため、
  動画・カメラ・画面共有のソース種別を問わず確実に映ります。
```

### レンダリング: Coons patch

8点の制御点（4コーナー + 4辺中点）から二次ベジェ曲線で各辺を定義し、Coons patch 公式で内部を補間。32×32 メッシュに分割して GPU で描画します。

```
通過点 → ベジェ制御点変換: C = 2M - 0.5(A + B)
Coons patch: P(u,v) = (1-v)·top(u) + v·bot(u) + (1-u)·left(v) + u·right(v)
             - bilinear(u,v)
```
