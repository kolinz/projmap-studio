# ProjMap Studio

> プロジェクションマッピングツール  
> 動画・ライブカメラ・画面共有をプロジェクタで自由な形に投影できます

---

## Windows での動作

**透明ウィンドウの要件**  
Windows 10 (1903以降) または Windows 11 が必要です。それ以前では透明ウィンドウが動作しません。

**透明ウィンドウが白くなる場合**  
GPU ドライバやコンポジター設定の問題で背景が白くなることがあります。起動オプションで回避できる場合があります：

```bash
npm start -- --disable-gpu
```

**パスの扱い**  
ファイルパスは `pathToFileURL()` を使って変換しているため、Windows の `C:\...` 形式も正しく動作します。

## インストールと起動

```bash
git clone https://github.com/kolinz/projmap-studio.git
cd projmap-studio
npm install       # 初回のみ（数分かかります）
npm start
```

**必要環境**: Node.js 24 以上 / Electron 42 以上 / WebGL 対応GPU

## 基本的な使い方

### ステップ 1 — サーフェスを追加する

左パネルの **「+ Add Surface」** をクリックすると、画面中央にサーフェス（投影エリア）が現れます。

複数のサーフェスを重ねることができます。追加するたびに色が変わります。

---

### ステップ 2 — 動画またはカメラを割り当てる

サーフェスをクリックして選択（枠が光ります）してから：

| 操作 | 方法 |
|------|------|
| 動画ファイルを使う | 左パネル「📁 Load Video」→ MP4 / WebM ファイルを選択 |
| カメラ映像を使う | 左パネル「📷 Live Camera」をクリック |

動画を読み込むとエディタにサムネイルが表示されます。  
実際の再生はプレビュー画面で行われます（ステップ 4 参照）。

---

### ステップ 3 — 形を合わせる

サーフェスを選択した状態で、ハンドルをドラッグして形を調整します。

```
  ●────◆────●   ← ● コーナー（四隅）
  │           │      ◆ エッジ中点（辺の湾曲）
  ◆           ◆
  │           │
  ●────◆────●
```

| ハンドル | 動かすと… |
|----------|-----------|
| ● コーナー（大きい丸） | 四隅を変形 — 台形や平行四辺形にできる |
| ◆ エッジ中点（ひし形） | 辺を湾曲させる — 曲面への投影に使う |
| 枠の中をドラッグ | サーフェス全体を移動 |

調整後は **Ctrl+Z** で元に戻せます（50ステップまで）。

---

### ステップ 4 — プレビュー（実際に投影する）

1. ツールバーの **「DISPLAY」** でプロジェクタ側のモニターを選択
2. **「▶ PREVIEW」** をクリック → プレビューウィンドウがプロジェクタ画面に開く
3. 動画が再生され、サーフェスの形に合わせて投影される

プレビュー中もエディタ側でハンドルを動かして微調整できます。

#### 緊急時
- **「■ BLACKOUT」** → 投影を瞬時に真っ暗にする（発表の合間など）
- **B キー** でも同じ操作ができます

---

### ステップ 5 — プロジェクトを保存する

ツールバー **「EXPORT」** → `projmap_project.json` として保存されます。

次回は **「IMPORT」** で読み込めば、サーフェスの位置がそのまま再現されます。  
※ 動画ファイルのパスも保存されますが、PCや場所が変わると再度読み込みが必要です。

## キーボードショートカット

| キー | 操作 |
|------|------|
| `N` | サーフェスを追加 |
| `P` | Preview / Edit 切り替え |
| `B` | Blackout オン/オフ |
| `Delete` | 選択中のサーフェスを削除 |
| `Esc` | 選択を解除 |
| `Ctrl + Z` | 元に戻す |
| `Ctrl + Shift + Z` | やり直す |

## 座標の数値入力

ハンドルをクリックすると、左パネルに **X・Y の数値フィールド** が表示されます。  
単位はツールバーの出力解像度（デフォルト 1920×1080 px）に対応しています。

例: 出力解像度 1920×1080 の場合、画面中央は `X: 960, Y: 540`

## よくある問題

**Q. 動画を読み込んでもエディタに動きがない**  
A. 正常です。エディタはサムネイル（静止画）を表示し、動画の再生はプレビュー画面で行われます。「▶ PREVIEW」を開いてください。

**Q. カメラが認識されない**  
A. ブラウザのカメラ権限をElectronが要求します。ダイアログが出たら「許可」を選んでください。それでも動かない場合は `/dev/video0` がアクセス可能か確認してください。

**Q. プレビューウィンドウがどこかに消えた**  
A. 「DISPLAY」セレクタで正しいモニターを選んでから「▶ PREVIEW」をクリックしてください。

**Q. 投影エリアの外が黒くならない**  
A. Wayland 環境では透明ウィンドウが動作しない場合があります。X11 セッションで起動してください: `GDK_BACKEND=x11 npm start`

**Q. プロジェクトを読み込んだら動画が映らない**  
A. 保存時のパスにファイルがあれば自動で読み込まれます。ファイルを移動した場合は再度「📁 Load Video」で読み込んでください。

```
│   └── undo.js              # UndoHistory クラス（最大50ステップ）
└── preview/
    ├── index.html           # プレビュー HTML
    └── app.js               # 透明 WebGL ウィンドウ・動画再生
```

### 座標系と透明ウィンドウの仕組み

```
制御点の保存形式: [0,1] 正規化 (ウィンドウサイズ非依存)
  └─ 頂点シェーダーでクリップ空間に変換
     gl_Position = vec4(u*2-1, -(v*2-1), 0, 1)

プレビューウィンドウ:
  BrowserWindow({ transparent: true, frame: false })
  WebGL clearColor(0, 0, 0, 0)
  └─ サーフェス外 = alpha=0 → OS が透過 → プロジェクタには黒（発光ゼロ）

IPC 設計:
  sync-layout  (4フレームに1回) ... コーナー座標・opacity
  sync-source  (ソース変更時のみ) ... ファイルパスのみ転送、データコピーなし
  video-command ... 再生・停止・先頭に戻る
```

### レンダリング: クーンズパッチ

8点の制御点から二次ベジェ曲線で各辺を定義し、Coons patch 公式で内部を補間。  
32×32 メッシュ（2048 三角形/サーフェス）に分割して GPU で描画します。

```
通過点 → ベジェ制御点変換: C = 2M - 0.5(A + B)
Coons patch: P(u,v) = (1-v)·top(u) + v·bot(u) + (1-u)·left(v) + u·right(v)
             - bilinear(u,v)   ← 重複補正項
```
